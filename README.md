# The Game Table

Minimal static game catalog for GitHub Pages.

Pages: `index.html`, `calendar.html`, `games/dragonbane.html`, `games/basic-fantasy.html`, `games/shadow-of-the-demon-lord.html`, `games/dnd-5e.html`, `games/mothership.html`, `games/call-of-cthulhu.html`.

To publish: GitHub repository **Settings > Pages > Build and deployment > Deploy from a branch**, select `main` and `/(root)`, then save. Website URL: https://kelodec.github.io/game-index/

## Calendar

`calendar.html` embeds the gaming group Google Calendar in Eastern Time (`America/New_York`). Manage sessions in Google Calendar; event changes do not require republishing this site. Calendar visibility follows its Google sharing settings. A direct calendar link is provided if embedding is blocked or sign-in is required.
