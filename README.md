# The Game Table

Minimal static game catalog for GitHub Pages.

Pages: `index.html`, `games/dragonbane.html`, `games/basic-fantasy.html`.

To publish: GitHub repository **Settings > Pages > Build and deployment > Deploy from a branch**, select `main` and `/(root)`, then save. Website URL: https://kelodec.github.io/game-index/

The illustrations in `assets/` are original stylized SVG artwork rather than publisher cover art.

`noindex` metadata and `robots.txt` discourage search indexing but do **not** make this public site private. Do not post sensitive personal information here.
